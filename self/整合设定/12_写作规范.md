# 写作规范

## 使用方式与规则层级

本文件用于章纲、正文和交稿验收，不代替各世界观模块。使用时先判断规则层级，再决定修改范围：

| 层级 | 含义 | 处理方式 |
| --- | --- | --- |
| 硬红线 | 对象、视角、因果、身份权限、资源连续性等基础逻辑 | 违反即退回章纲或场景层重写，不做表面润色 |
| 默认规范 | 字数、场景数、信息密度、段落长度和常用节奏 | 原则上遵守；确有明确叙事收益时可以偏离，但必须保持可读性与完整状态变化 |
| 优化建议 | 高频词、比喻、环境辨识物和表达偏好 | 在结构通过后处理，不得为了语言漂亮改坏事实与人物动机 |

单章执行顺序固定为：读取状态与相关设定 → 填章卡 → 写干净正文 → 结构硬检 → 语言精修 → 生成章节概况并更新状态卡。不要在结构尚未通过时反复逐句润色。

## 设定权威与世界观披露

正文开写前按下表确定事实来源：

| 内容 | 权威来源 | 冲突处理 |
| --- | --- | --- |
| 术语、对象定义与版本冲突 | 《14_术语与冲突裁定.md》 | 覆盖旧稿、旧版称谓和作者临时印象 |
| 世界、地域、力量、人物、地图与遗蜕细节 | `00` 至 `16` 对应模块 | 专项总表的编号、数值和状态优先于剧情提案 |
| 已经发生的正文事实 | `正式章节`及对应`章节概况` | 正式正文为最终事实；概况必须随正文修订同步更新 |
| 下一章开场状态 | `写作流程/2.当前状态追踪卡.txt` | 若与正式正文冲突，先按正文修正状态卡，再开写 |
| 日常执行与输出格式 | `写作流程/1.最高律令.txt`及日常工作台 | 与本规范配合使用，不另造第二套流程 |

- 底层角色的认知必须局部且可能错误。
- 角色可以说错，限知旁白也可以跟随角色作出错误推断，但正文必须把它写成“某人认为、传闻如此或暂时判断”，不能用无归属的客观叙述把错误说成事实。
- 角色不使用超出自身经历和修为的知识或比喻。
- 前期不用大区域地名和“末法时代”等标签直接解释世界。
- 五品遗藏、十位至强和道祭真相随剧情逐层披露。
- 涉及世界历史年代时，作者时间轴统一换算为末法历；故事开篇为末法历30012年。外域人物可使用地方纪年，但需在设定记录中注明对应年份。

### 核心对象不得混用

## 叙事视角与场景

- 正文以第三人称限知视角为主，默认跟随林澈。叙述只能提供当前视角人物能够感知、回忆或合理推断的信息。
- 同一场景内不得无提示切入他人内心。更换视角或发生明显时空跳转时，统一使用 `---` 切场，并在新场景开头尽快明确人物、地点和时间；普通段落换行不承担切场功能。
- 配角视角只在林澈无法见证、且该视角能制造关键信息差、人物弧线或威胁时使用；不能为了提前解释反派计划而频繁切换。
- 每个场景必须具备“人物目标—阻碍—状态变化”。如果场景结束后人物的处境、认知、关系、资源和决定均未改变，应压缩或删除。
- 单章通常安排二至四个场景。战斗高潮可以只写一个完整场景；过渡章可以用一个现实主场景串联若干简短结算。
- 时间跳跃、地点转移和忆境内外切换必须给出明确锚点，不能让读者靠上下文猜测角色是否已经回到现实。

## 语言与排版

- 以现代白话为叙述主体，保留修仙世界应有的称谓和语感，但不堆半文半白长句、生僻古词与成串四字词。
- 移动端阅读以一至四句为常见段落长度。动作和对话段可以更短，说明段一般不超过约一百五十字；不把每一句都切成独立段落。
- 对话统一使用中文引号“”；省略号使用“……”；破折号使用“——”。同一处标点不重复堆叠。
- 战斗中优先使用准确动词和空间关系，不用大量副词替代动作力度；招式名只在角色确实知道且有辨识价值时出现。
- 正文数字以阅读自然为准：灵力、恢复进度、时间窗口和承载值等规则信息可用阿拉伯数字；人物口头估算优先使用“约三成”“十来步”等自然说法。
- 蓝星网络用语、游戏术语和现代管理词只能出现在林澈内心的短暂类比中；对本界人物说话时必须转译为他们能够理解的表达。


## 身份、职责与行为边界

人物首先是社会关系中的人。其日常行动必须符合身份职责、权力层级、专业能力、可支配时间与旁人期待，不能因为作者需要某个场景就让任何角色承担任何工作。

### 基本原则

- 先判断“这件事按组织常态应由谁负责”，再决定出场人物。能由下属、族人、执事、护卫或专业修士完成的事务，上位者通常负责下令、协调、检查和承担结果，而非亲自执行每个步骤。
- 身份越高，时间越稀缺，行动越具有政治含义。族长去粮田巡查是履职，亲自连续种田通常是失职；宗主查看炼丹房是监督，长期代替学徒烧火会使管理职责无人承担。
- 专业工作需要相应经验。战力强不等于会炼丹、辨矿、审账、种植或修阵；主角也不能仅凭现代常识立即取代本界专业人员。
- 公职行为与私人行为必须区分。族长可以私下帮亲属收粮，但不能把这种偶发行为写成其日常主要职责；执法者可以救熟人，却要承担徇私嫌疑和制度后果。
- 身份不会绝对禁止行为，但越界必须有原因。灾荒、敌袭、人手断绝、伪装潜入、示范教学、赎罪、个人习惯或政治表态都可以让人物亲自下场，正文必须让读者看见原因与代价。
- 角色越过职责边界后，原本职责不会自动消失。族长亲自参战时，必须有人代理部落决策；医修离开伤营寻人时，伤员处置就会受影响。

### 身份行为参考

| 身份 | 通常亲自处理 | 通常交由他人 | 亲自越界时需要的理由 |
| --- | --- | --- | --- |
| 族长、宗主、堡主 | 决策、资源分配、任命、谈判、重大审判、最高风险处置 | 日常耕作、普通巡逻、逐户收税、基础搬运和重复生产 | 灾难救急、公开表态、无人可用、目标只有本人能处理 |
| 长老、执事、队长 | 执行上层决策、管理专业事务、训练、监督和带队 | 与职责无关的基层杂务、越权决定整个组织命运 | 临时授权、上级失联、专业紧急情况或争权行为 |
| 修士战斗人员 | 护卫、狩猎、探索、对抗灵性威胁、维护修行设施 | 长期替代凡人完成低收益重复劳动 | 灵力生产需要、灾时抢救、修炼任务或换取生存资源 |
| 丹师、阵师、炼器师 | 诊断、设计、关键步骤、疑难修复和成果验收 | 普通采集、搬运、守夜及可由学徒完成的重复工序 | 保密、防破坏、材料特殊或学徒不足 |
| 商队首领、掌柜 | 定价、路线、信用、护卫配置和大额交易 | 每件货物装卸、普通叫卖和逐笔跑腿 | 验货、防内鬼、重要客户或局势失控 |
| 普通族人、学徒、杂役 | 生产、维护、跑腿、基础操作和提供一线经验 | 未获授权的资源分配、外交承诺和高阶专业判断 | 被迫应急、掌握独有情报或借机改变身份 |
| 外来者、客卿 | 完成约定职责、提供专长、有限协助 | 默认参与内部决策、调用公共资源和指挥本地成员 | 已建立功劳、取得正式授权、交换条件或内部派系支持 |

### 权力与信息限制

- 有地位不等于知道全部秘密。族长掌握部落库存和主要威胁，不必知道每个猎人的私怨；宗门高层知道战略，也可能不了解底层执行中的漏洞。
- 有权下令不等于命令必然执行。命令需要通过亲信、队长、账册、印信或利益关系落地，还会受到距离、派系、资源和执行者理解影响。
- 下位者当面反驳上位者需要身份资本，例如功劳、证据、专业不可替代性、派系支持或危急局势；否则更可能私下抱怨、拖延、阳奉阴违或寻找中间人。
- 上位者公开认错、亲自劳作、进入险地或给出私人承诺都属于稀缺行为，应当改变声望、派系判断或群众态度，不能发生后无人重视。
- 资源的使用权、保管权和所有权必须区分。保管遗蜕的人未必能决定其出售，发现坐标的人未必拥有坐标，族长也不能无代价把公共粮仓当作私产。

### 写作执行

- 安排人物行动前，依次检查：谁负责、谁有权、谁有能力、谁有时间、谁从中得利、谁会反对。
- 若某角色亲自处理明显低于或超出其身份的事务，正文至少交代“为何必须是他”“原职责由谁接手”“旁人如何理解”三项中的两项。
- 需要重要人物出现在基层场景时，优先使用巡查、验收、慰问、调查、示范、问责、秘密观察或突发事故等符合身份的进入方式。
- 不为了让主角听见情报，就让高层在公开场合直说秘密；应通过授权旁听、偷听风险、任务简报、账册痕迹、派系试探或信息误差完成披露。
- 不为了制造冲突，就让上位者无理由亲自辱骂、动手或处理琐事。成熟掌权者更常通过规则、资源、任命、拖延和代理人施压。
- 外来者在取得信任前，不得独自清点公仓、接触完整库存、读取秘密坐标档案或代表族长发号施令。剧情确需接触时，必须有授权人陪同、限定范围和明确目的。
- 上位者设置的考验必须真正检验目标能力。不能用“故意派去做无关工作，期待他擅自绕路”之类只能依赖巧合、违令或作者安排成立的测试。
- 组织掌握敏感信息时，要区分谁能知道总量、谁只知道自己经手部分、谁负责记录、谁有权调拨，不能让一场随意闲谈公开全部底牌。

## 修为与战斗

- 境界统一为“炼气”，不用旧称“行气”。炼气分九层。
- 规则依赖具体层数时必须写明“炼气几层”，不能只写炼气初期。例如主动运转魂印至少需要炼气二层，人物登记与正文表现必须相符。
- 写清修为、灵力存量和具体战力，例如能释放几次术法、支撑多久、跑多远。
- 灵力存量用“成”，不用抽象的“灵力充足”。
- 低阶修士因灵力难补，平时不轻易释放术法；训练常用可回收灵力的“干烧”。
- 灵石标明品级。
- 忆境压制只保留经验与法则理解，不能让高境界用肉身或神魂绕过上限。
- “一成灵力”只表示角色自身满状态的十分之一，不用于跨境界比较；写恢复时同时交代资源与所需时间。
- 同境小层差可以由功法、器物、人数和环境弥补；跨一大境胜利必须有克制、阵法、伤势、负重或多人消耗等已铺垫条件；跨两大境以上不得个人正面斩杀。
- 临战突破必须在积累、核心结构、道路认知和突破资源已经齐备时发生，战斗只能成为最后触发，不能凭情绪补全条件。
- 清浊道净化必须写出接触、解析、承载与排放；对高阶浊力只能局部处理或借外力，不能写成无消耗克制。

## 因果、伤势与资源连续性

### 行动前后账

重要行动开写前先建立作者用状态卡，正文不必完整展示，但每项必须有答案。

| 项目 | 行动前必须明确 | 行动后必须更新 |
| --- | --- | --- |
| 时间与地点 | 当前日期、距期限多久、人物为何在此 | 经过多久、移动到哪里、是否赶得上下一事件 |
| 身份与权限 | 谁授权、谁陪同、能接触多少信息与资源 | 是否越权、谁得知、信任和政治后果如何变化 |
| 身体与神魂 | 伤势、疲劳、浊染、魂印状态 | 哪项加重或恢复，恢复凭什么、需要多久 |
| 修为与灵力 | 具体层数、当前余量、可用术法与器物 | 实际消耗、剩余余量、下一次补充来源 |
| 装备与负重 | 穿戴、消耗品、愿力携入费、承载空位 | 获得、舍弃、损坏、掉落与归属 |
| 情报 | 角色已知事实、误判和未验证假设 | 哪项被证实、推翻或仍然未知 |
| 行动目的 | 角色想得到什么，拒绝什么，失败底线是什么 | 得失、代价及下一步选择 |

- 前文已经明确的事实不得在章末反向遗忘。角色说过原因、看过出口或得到数字后，后文只能修正它，不能当作从未解释。
- 角色尚未做过的行动，不得在复盘中写成已经经历。例如只完成感知训练，就不能回忆“进入时身体承受的压力”。
- 公共身份需要由人物主动建立。林澈若要伪装失忆，必须在具体场景中作出这个选择并维持口径，旁白不能提前替他完成伪装。


### 修仙资源信号

- 废土贫困不等于世界退化成纯粹古代乡村。前期现实章每章至少出现一项与当前境界相关、且影响生活或决策的修仙资源信号，例如枯败灵田、灵谷配额、残符修补、碎灵石、妖兽灵肉、聚灵阵维护或回气药价格。
- 凡物用于吃住、工具和历史质感；涉及冒险回报、修炼成长或势力争夺时，主要对象必须是灵物、坐标、愿力、功法、法则信息或修行生产能力。
- 凡物成为重要奖励时，必须具有不可替代的历史、机制或生产价值。普通铁锅、干粮和衣物不能压过同场灵谷、丹药、符箓与灵材成为修仙收益记忆点。
- 资源数字要产生行动后果。库存两个月、税期二十日、接入消耗一成等数字一旦出现，人物的方案、争执和时间安排必须围绕它变化。

## 遗藏与忆境

- 魂印是幽冥魂尊道韵与天道共同留下的后天体系，不是自然器官。
- 每处遗藏都必须有一位历代合道者作为道韵锚点；普通人、群体、地域与时代只能作为该至强亲历内容的一部分出现。
- 凡忆写至强在炼气、筑基阶段的一段短经历，表面可以只是普通人的生活，但须埋下锚点至强在场或受其影响的证据；群体事件从玄章起作为主体使用。
- 凡忆不写多层迷宫、完整人格长谈等高品结构。
- 忆境必须有生活痕迹，让记忆中的人正在做事，而不是站着等闯入者触发台词。
- 探索必须存在意外、风险和不可预料反应。
- 稳定化后属于公共资源，不认主，不变成卡灵。
- 稳定化的情感收束保持轻，重点尽快转入现实遗蜕的价值与争夺。
- 未知遗藏的发现具有随机性，已记录坐标可定向接入；不要把“随机发现”误写成每次进入都随机换藏。
- 前期地图必须有可辨认的区域结构、至少二十个候选搜索点和多个撤离方向；单层凡忆不等于狭小房间。
- 地图每轮只激活部分搜索点，物品从符合场景的加权池刷新。随机性改变路线和收益，不得破坏世界逻辑。
- 修仙资源必须是前期地图的主要收益。凡忆以炼气级灵谷、灵药、符箓、灵材和灵兵为主，玄章以筑基级丹药、灵器胚、灵矿和阵件为主；凡物只作生存补给或场景细节。
- 灵物化实后只降低品质或完整度，不得惯常退化成凡物。角色获得资源后要写出修炼、炼化、交易、装备或部落生产上的实际用途。
- 搜索、交战和撤离必须互相影响：高价值搜索制造暴露，战斗消耗撤离资源，携带选择迫使角色放弃部分收益。
- 连续地图需通过物品、账册、坐标或人物因果相连，不能只靠主角碰巧发现下一张图。
- 地图不是一次性副本。剧情推进后仍可回到旧图搜索、争夺、练队或追查遗漏线索；重复进入必须利用已学地形，同时面对新的点位、物品、事件和对手组合。
- 稳定化只结束核心恢复主线，并触发“法则落定、载体成为遗蜕、遗蜕首次具现”，不关闭地图；后续写作使用回响事件和受限随机产出，避免无限刷取同一珍品。
- 任何具名遗蜕在进入正文、主线或伏笔前，必须登记到《16_遗蜕登记总表.md》并取得唯一编号；其他文档不得另设一套冲突的能力数值。
