小说世界观推导顺序
第一阶段：确定故事核心
1. 题材与故事类型
先确定小说属于什么类型：

玄幻
修仙
科幻
都市
末世
悬疑
历史
西幻
题材决定需要重点构建哪些设定。

例如：

修仙重点：力量、资源、宗门、长生
科幻重点：技术、文明、社会、伦理
末世重点：灾难、资源、生存、秩序重建
2. 核心主题
确定小说要探讨的问题：

长生是否值得？
秩序和自由哪个更重要？
人能否反抗命运？
极端环境下人性会变成什么样？
力量是否必然导致腐化？
主题会影响世界中的核心矛盾。

3. 核心矛盾
根据主题，确定世界正在面临的根本冲突。

例如：

主题：生命是否应该分贵贱？
核心矛盾：修士为了长生，不断掠夺凡人的生命。

故事的其他设定最终都应该服务于这个矛盾。

第二阶段：构建世界基础
4. 世界起源
先回答：

世界如何诞生？
是自然形成还是被创造的？
神明是否存在？
世界有几层？
是否存在其他世界？
世界为什么会变成现在这样？
世界起源可以推导出：

世界规则、神话传说、种族起源、宗教信仰。

例如：

世界由一位陨落的古神身体化成。

可以继续推出：

山脉是古神的骨骼
河流是古神的血液
灵气来源于古神残存的力量
修炼是在吸收古神力量
古神可能会因修炼者过多而苏醒
5. 世界底层规则
根据世界起源，确定世界如何运行：

时间规则
空间规则
生死规则
灵魂规则
能量规则
因果规则
穿越规则
力量上限
不可违背的禁忌
这一部分决定世界中什么事情可以发生。

推导关系：

世界起源 → 世界规则 → 力量来源与生命形态。

6. 世界形态与空间结构
根据规则确定世界的形态：

单一大陆
多块大陆
星球
多个星系
多重世界
人间、仙界、冥界
无限空间或副本世界
继续确定：

世界有多大
世界之间如何连接
是否存在边界
普通人能否跨越世界
不同区域的规则是否相同
7. 地理与自然环境
确定世界的自然条件：

山脉
河流
海洋
平原
沙漠
森林
气候带
灾害区域
禁地
秘境
推导关系：

世界形态 → 地理环境 → 生存条件 → 文明分布。

例如：

北方终年严寒
→ 农业困难
→ 依靠狩猎和放牧
→ 人口稀少
→ 部落结构
→ 崇尚力量
→ 经常南下掠夺。

8. 资源分布
根据地理环境确定资源：

粮食
水源
木材
矿产
灵石
药材
能源
战略资源
稀有材料
要确定：

资源在哪里
数量有多少
如何开采
谁在控制
能否再生
是否存在替代品
推导关系：

地理环境 → 资源分布 → 生产方式 → 经济体系。

第三阶段：建立文明基础
9. 种族与生命形态
根据自然环境和世界规则，设计生物和种族：

种族如何诞生
生活在哪里
依靠什么生存
有什么生理特征
寿命是多少
是否能够修炼
如何繁衍
有什么天赋和弱点
推导关系：

世界规则＋自然环境 → 种族形态。

例如：

地下没有阳光
→ 地下种族视力退化
→ 听觉和震动感知发达
→ 依靠矿物和菌类生存
→ 形成地下城市
→ 发展出矿石加工文明。

10. 生产方式
根据环境和资源，确定人们怎样获得生活资料：

狩猎
采集
农业
畜牧
手工业
工业
魔法生产
自动化生产
掠夺
位面贸易
生产方式需要回答：

食物怎么来
武器怎么制造
房屋怎么建造
谁负责劳动
技术掌握在谁手里
生产效率有多高
推导关系：

资源分布＋技术水平＋人口规模 → 生产方式。

11. 技术或力量体系
确定文明依靠什么力量发展：

科技
魔法
修仙
武道
神术
异能
血脉
机械
多种体系并存
需要依次设置：

力量来源
使用条件
修炼或学习方法
等级划分
能力表现
资源消耗
使用代价
力量上限
克制关系
社会影响
力量体系不仅影响战斗，也会改变生产和社会。

例如：

修士能够控制天气
→ 农业不再完全依赖自然降雨
→ 控制修士就等于控制粮食
→ 宗门掌握农业命脉
→ 王朝必须与宗门合作。

12. 人口与聚居方式
根据生产效率、环境和危险程度确定：

人口总量
人口密度
城市规模
村庄数量
人口寿命
出生率与死亡率
人口迁移
城乡关系
推导关系：

食物产量＋医疗水平＋环境危险 → 人口规模。

人口规模又会影响：

军队规模
城市数量
税收能力
战争强度
统治方式
13. 交通与通信
根据技术和地理条件确定：

步行
马匹
船舶
飞行法器
传送阵
火车
飞船
通信法术
网络系统
它会决定：

国家能够统治多大范围
消息传播需要多久
商品能运送多远
军队调动需要多久
不同地区的文化差异有多大
推导关系：

地理环境＋技术水平 → 交通通信 → 政权规模。

第四阶段：推导经济与社会
14. 经济体系
经济体系不能凭空决定，要根据以下设定推导：

资源分布＋生产方式＋人口规模＋交通条件＋技术水平。

需要设置：

主要产业
商品种类
贸易路线
市场结构
货币
物价
税收
土地制度
借贷制度
黑市
财富分配
例如：

灵石是修炼必需品
→ 灵石需求极高
→ 灵石具有稳定价值
→ 灵石成为货币
→ 矿脉成为战略资源
→ 宗门争夺矿脉
→ 矿区城市成为政治中心。

15. 职业体系
根据生产方式和经济活动设计职业：

农民
商人
工匠
士兵
官员
医师
修士
炼丹师
阵法师
冒险者
情报贩子
推导关系：

社会需求＋技术分工 → 职业体系。

职业体系还会影响：

人才培养
身份地位
收入差距
行会与组织
阶级流动
16. 阶级结构
根据资源和生产资料的控制权划分阶级：

谁拥有土地
谁控制矿产
谁掌握力量
谁掌握知识
谁负责生产
谁获得大部分财富
可能形成：

皇族
贵族
宗门修士
商人
工匠
平民
奴隶
流民
推导关系：

资源控制权＋生产关系＋力量差距 → 阶级结构。

例如：

修炼天赋无法后天改变
→ 有天赋者掌握超凡力量
→ 修士与凡人差距扩大
→ 修士成为统治阶层
→ 血脉和天赋成为身份标准。

17. 家庭与教育制度
根据经济和阶级结构确定：

家庭是一夫一妻还是宗族制
婚姻是否自由
家产如何继承
谁拥有受教育权
谁培养修士或技术人员
教育是否被垄断
普通人如何改变阶级
推导关系：

生产方式＋财产制度＋阶级结构 → 家庭与教育制度。

教育又决定：

知识传播速度
人才数量
阶级是否固化
技术发展速度
第五阶段：推导政治秩序
18. 组织与势力
根据共同利益形成组织：

家族
宗门
商会
教会
学院
军团
冒险者公会
地下组织
国家
每个势力都要有：

核心利益
掌握的资源
成员来源
组织结构
领袖
行动方式
内部派系
外部敌人
推导关系：

人群利益＋资源控制＋共同信仰 → 势力形成。

19. 政治制度
根据力量分布和交通通信条件确定统治方式：

王朝
帝国
城邦
联邦
部落
宗门联盟
神权国家
公司统治
人工智能管理
政治制度主要回答：

谁制定规则
谁执行规则
谁拥有军队
谁负责收税
统治者如何产生
权力如何继承
地方是否服从中央
推导关系：

阶级结构＋势力关系＋武力分布＋交通条件 → 政治制度。

20. 法律与秩序
根据统治阶级的利益制定法律：

什么行为合法
什么行为犯罪
如何审判
如何惩罚
不同阶级是否同罪
修士和凡人是否适用同一套法律
国家、宗门和家族谁有执法权
推导关系：

政治制度＋统治者利益＋社会道德 → 法律体系。

要注意：

法律不一定代表公平，往往首先保护现有秩序。

21. 军事体系
根据敌人、技术和经济能力建立军事体系：

军队来源
征兵或募兵制度
武器装备
后勤补给
指挥体系
军队规模
超凡者在战争中的作用
城防与要塞
战争成本
推导关系：

威胁类型＋经济能力＋人口规模＋技术水平 → 军事体系。

22. 势力外交关系
根据资源需求、历史恩怨和现实利益，建立：

联盟
敌对
附庸
贸易
冷战
渗透
联姻
代理战争
表面合作
秘密协议
推导关系：

资源矛盾＋地缘位置＋实力差距＋历史问题 → 外交关系。

第六阶段：推导文化与精神
23. 历史背景
当世界基本框架形成后，开始补全历史发展：

世界诞生
种族出现
文明建立
技术或力量被发现
国家与势力形成
资源争夺
重大战争
王朝或文明更替
灾难发生
形成故事开始时的局面
历史背景可以反过来解释现实制度：

历史事件 → 集体记忆 → 社会制度与势力关系。

例如：

三百年前发生妖族入侵
→ 人族建立修士军团
→ 军团在战后没有解散
→ 军团逐渐掌握政治权力
→ 现在形成军事贵族统治。

所以你提到的“历史背景推经济体系”是可行的，但更准确的说法是：

历史背景改变资源归属和生产关系，从而塑造经济体系。

例如：

战争摧毁农田
→ 粮食减产
→ 粮价上涨
→ 商会囤积粮食
→ 商会控制城市经济
→ 政府依赖商会提供军费。

24. 语言、习俗与生活方式
根据地理、生产和历史确定：

语言与文字
衣食住行
节日
礼仪
婚丧习俗
娱乐方式
建筑风格
姓名习惯
社交规则
地区文化
推导关系：

地理环境＋生产方式＋历史经历 → 生活文化。

25. 宗教与信仰
根据世界起源、死亡规则和历史经历确定：

人们信什么
神是否真实
神是否回应信徒
死后世界是否存在
教会掌握什么力量
宗教与政权是什么关系
是否存在异端
信仰是否产生超凡力量
推导关系：

世界真相＋人类对未知的解释＋政治需求 → 宗教信仰。

26. 社会价值观
根据历史和社会制度形成主流价值观：

崇尚力量还是智慧
重视个人还是集体
重视血统还是能力
如何看待生命与死亡
如何看待财富
如何看待战争
如何看待异族
如何看待超凡者
推导关系：

历史记忆＋阶级利益＋宗教信仰 → 社会价值观。

第七阶段：从世界观推导故事
27. 世界当前局势
把前面所有设定汇总，找出世界现在的问题：

资源即将枯竭
王朝走向衰败
新技术正在出现
旧阶级阻止改革
异族准备入侵
神明即将苏醒
世界规则开始崩坏
各势力争夺权力
推导关系：

历史遗留问题＋现实资源矛盾＋力量变化 → 当前局势。

28. 世界核心矛盾
从当前局势中提取最重要的矛盾：

资源不够，但各势力都想发展
旧制度稳定，但压制了多数人
新力量能够改变世界，却可能带来毁灭
统治者想维持秩序，底层想改变命运
众生想要长生，但长生会消耗世界本源
29. 主角身份
主角最好处于核心矛盾的交叉点。

根据世界矛盾推导主角身份：

被压迫阶级的人
旧制度的受益者
新力量的发现者
两个敌对种族的混血
掌握历史真相的人
即将被淘汰的职业者
世界规则的例外
主角不能只是“生活在世界里”，而应该与世界矛盾直接相关。

30. 主角目标
根据身份和处境生成目标：

主角处境 → 生存需求 → 初期目标 → 发现真相 → 最终目标。

例如：

主角是矿区奴工
→ 想逃出矿区
→ 发现灵石正在污染人体
→ 发现宗门故意隐瞒真相
→ 决定摧毁宗门的灵石垄断。

31. 反派与阻力
反派要从世界制度中自然产生：

既得利益者
统治者
资源垄断者
宗教领袖
军事集团
极端改革者
世界规则的维护者
推导关系：

主角想改变的东西 → 因此会受损的人 → 反派。

反派不一定单纯邪恶，他可能认为：

旧制度虽然残酷，但至少能维持世界稳定。

32. 故事主线
最后形成完整主线：

世界问题 → 主角受到影响 → 主角产生目标 → 势力阻止主角 → 主角探索真相 → 矛盾持续升级 → 主角作出最终选择 → 世界发生改变。

实际创作时，最关键的是让每项设定都能回答两个问题：

它为什么会形成？它会造成什么结果？

只要每项设定都有“前因”和“后果”，世界观就会自然形成一张相互关联的因果网络。
