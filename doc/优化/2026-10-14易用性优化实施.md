## 已完成

| 区域 | 优化 | 行为边界 |
| --- | --- | --- |
| 全局主题 | 移除不完整的自动深色覆盖，明确使用浅色主题，修复白底上的浅色操作文字 | 未新增完整深色主题 |
| 写作布局 | 压缩页面与章节头部；窄屏章节设置使用图标；删除重复的正文标题；字数合并到格式工具栏 | 不改变章节切换、删除、移动和保存流程 |
| 编辑器 | 增加撤销、重做按钮及可用状态；编辑区内支持 Ctrl+S / Cmd+S | 调用现有正式保存方法；不误保存助手要求或本章计划；保留重复保存保护 |
| 写作助手 | 选区改写、润色增加选择/重新选择正文片段；窄屏临时收起助手并聚焦正文；检查页返回正文时收起窄屏助手 | 重新展开保留操作类型、写作要求及已挂载候选；不改生成时的选区锚点；历史、知识、导入仍保持原有模态边界 |
| 可读性 | 模型、费用元信息从 9px 提升到 12px；模型名 13px；加深正常文字；助手候选采用 14px 与 1.8 行距 | 禁用态保留视觉区分 |
| 搜索 | 页面打开立即聚焦关键词；支持 Ctrl+K / Cmd+K 打开搜索；已在搜索页时重新聚焦 | 经现有路由链接进入，保留未保存离开确认；没有作品、作品切换或模态对话框打开时不执行快捷跳转 |
| 参考资料 | 章节记忆显示来源章节名与可用更新时间；支持按章节名搜索；窄屏选择或编辑资料时滚动到详情 | 复用一次章节列表查询与缓存；不逐条请求；没有章节元信息时保留原类型标题，不编造名称 |
| AI 任务设置 | 700px 及以下改用紧凑任务选择器，桌面保留任务网格；切换任务保留未保存参数 | 沿用原任务切换与保存逻辑，不自动提交设置 |
| 构思收集 | 去向分成构思笔记、用于创作、高级候选三组 | 所有选项值、候选流转、确认与写入规则保持不变 |

## 实测结果

写作页初始状态，正文上边缘与保存栏上边缘之间的无遮挡高度：

| 窗口 | 正文起点 | 保存栏起点 | 正文可视高度 |
| --- | --- | --- | --- |
| 1440×900 | 284px | 774px | 490px |
| 1366×768 | 284px | 683px | 399px |
| 1280×720 | 284px | 635px | 351px |
| 1024×768 | 284px | 683px | 399px |
| 800×640 | 280px | 555px | 275px |
| 390×844 | 278px | 638px | 360px |
| 320×568 | 278px | 459px | 181px |

此前 320×568 同类初始状态约为 17px，本轮增加约 164px。此测量不代表所有长章节标题、错误提示或软键盘展开状态下的保证高度。

浅色、深色系统偏好下，作品管理的“新建作品”均为白底深色文字：`rgb(63, 71, 66)`，不再切换成接近白色的文字。

## 暂缓与限制

- 搜索结果的对象标题、所属章节和修订时间需要后端搜索结果契约扩展，本轮只完成搜索入口与焦点，不通过猜测或逐条查询补充标题。
- 完整深色主题、阅读字号/行距偏好、专注模式和统一局部确认对话框留待独立实现。
- 参考资料目前仍使用列表与详情布局，本轮改善定位，没有实现手机式两级导航。
- 构思收集仅完成去向分组，消息内确认区的矮窗口滚动行为未重新设计。
- 没有打开用户真实作品、调用真实 AI、执行原生备份恢复或改动数据库结构。
- 未运行原生桌面持久化验收、移动软键盘、大数据量和 150%/200% 系统缩放专项测试。
