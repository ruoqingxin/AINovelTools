# R0-R2 P0 验收报告

日期：2026-08-27

## 已通过

- Rust workspace 测试通过。
- `cargo clippy --workspace --all-targets -- -D warnings` 通过。
- 前端 Vitest 测试通过。
- IPC 客户端契约检查脚本已加入 `pnpm check`。
- FeatureCatalog 和无项目健康状态已提供。
- 规划更新提供 `expected_version` 并发检查。
- 正文 JSON 根结构校验、稳定 block ID 和 SHA-256 已提供。
- 正文及规划历史表增加禁止 UPDATE/DELETE 触发器。
- RecoveryLog 持久化保存和查询命令已提供。
- 规划节点移动、循环检测和归档子节点处理已提供。
- 正文提供基于稳定 block ID 的基础三方合并接口。
- 编辑器提供未保存切换拦截和浏览器关闭提示。
- 项目级恢复候选查询和全局提示已接入。
- 三方合并冲突检查及冲突块提示已接入正文工作区。

## 尚未通过

- 恢复候选已在项目启动后的 AppShell 全局提示，并可在章节工作区恢复。
- `plan_nodes` 当前状态表仍保留兼容用途，后续可进一步收敛为从 `PlanRevision` 投影重建。
- 三方合并已提供 block 级后端接口和冲突块提示；复杂的逐块自动拼接策略仍保持人工确认。
- 真实桌面启动冒烟和故障注入测试尚未完成。

## P0 结论

P0/P1 的核心数据安全、并发、恢复、移动、差异和契约基础已经落地；R0-R2 仅剩真实桌面启动冒烟和完整故障注入验收。
