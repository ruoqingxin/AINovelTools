# R5 已知风险

| 风险 | 影响 | 缓解与验收 |
|---|---|---|
| 来源修订被归档或删除 | Fact 无法追溯 | Anchor 校验失败进入 `NEEDS_REVIEW`，集成测试覆盖 |
| 并发审核/定稿 | 覆盖他人决定 | 使用版本条件更新，返回 `CONFLICT` |
| 结构化 AI 输出漂移 | 候选污染正式表 | Schema 校验失败拒绝入库，只保留脱敏摘要 |
| 冲突规则过宽或过窄 | 误阻断或漏检 | 首批采用确定性规则，记录命中原因并准备样例集 |
| 定稿中途失败 | 知识与审计不一致 | 单事务写入并验证回滚、Outbox 不发送成功事件 |
| R4 人工门禁未补证 | 阶段状态误判 | R4 仍保持“未完全关闭”，R5 设计与实现记录分开 |
