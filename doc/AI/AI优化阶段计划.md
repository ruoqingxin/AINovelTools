# AI 优化阶段计划

## 文档状态

- 日期：2026-09-11
- 当前阶段：第一阶段已完成，准备进入第二阶段
- 适用范围：作品设定、大纲主线、分卷规划、章节拆分、正文书写、知识提炼

## 产品目标

AI 功能必须让作者保持控制权：每个任务都能补充自己的意见；每类任务都能单独选择模型、备用模型和生成参数；全局设置与项目覆盖边界清晰；运行记录、费用和质量反馈可追溯。未知能力不得用空壳或虚假成功冒充完成。

## 阶段一：生产化配置与费用治理

状态：已完成。

- [x] 六类任务均提供可选作者补充意见，并进入实际请求上下文。
- [x] 每类任务支持独立模型、备用模型、温度、最大输出、提示词和上下文预算。
- [x] 六类任务提供适合任务性质的推荐默认值，并支持单项恢复。
- [x] 设置页按任务选择已经配置且可用 Key 的聊天模型。
- [x] 支持全局配置和项目覆盖；项目批量应用会以事务保存六个任务。
- [x] 统一记录正文、规划和知识提炼的主模型、备用模型、尝试次数、回退原因、token 与费用快照。
- [x] 模型配置支持输入/输出单价与币种；设置页展示今日、近 30 天和项目累计估算费用。
- [x] 支持软预算：币种、每日上限、单项目累计上限；达到 80% 提示，超出只警告不中断。
- [x] 增加模型配置、项目覆盖、统一运行记录和用量汇总测试。

边界：

- 费用来自作者填写单价和估算 token，不是服务商真实账单。
- 软预算不代替服务商侧硬额度，也不阻止已经发起的生成。

## 阶段二：质量评测与回归基线

状态：待实施。

- [ ] 汇总每个任务、模型和提示词版本的有效样本数。
- [ ] 汇总正文候选有帮助率、需改进率、校验问题率和采用率。
- [ ] 在设置页展示质量回顾，帮助作者识别低质量模型或提示词版本。
- [ ] 建立脱敏评测样本格式和固定回归用例。
- [ ] 质量变化只提示、不自动替换用户配置。

## 阶段三：效率与故障恢复

状态：未开始。

- [ ] 提供面向题材和创作场景的任务预设，但保留逐项编辑。
- [ ] 支持请求成本预估、发送前预览和配置差异对比。
- [ ] 支持规划与知识提炼任务的可恢复重试、失败原因分类和继续处理。
- [ ] 支持批量运行前预算检查与任务级取消。

## 阶段四：按证据增强

状态：未开始。

- [ ] 只有质量和评测证明关键词/结构化检索不足时，才评估向量混合检索。
- [ ] 只有真实创作决策场景可验证时，才评估图谱、时间线或节奏分析。
- [ ] 任何高级能力先建立触发证据、ADR、隐私边界、失败路径和回滚方案。

- `cargo test --workspace`、前端检查、全量测试和生产构建通过。
- FeatureCatalog、接口契约、迁移清单和阶段验收记录同步更新。
