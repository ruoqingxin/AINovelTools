# R6 已知风险

| 风险 | 影响 | 准入要求 |
|---|---|---|
| 未满足门槛即引入高级架构 | 复杂度高于实际价值 | 未有触发数据、ADR 和验收案例时不得实现 |
| 检索评测数据泄露正文或隐私 | 云端边界失控 | 评测集必须脱敏、版本化并完成隐私确认 |
| 向量、Embedding 或分块版本混用 | 召回结果不可解释 | 每次模型、维度或分块变化都必须完整重建并记录版本 |
| Worker 或 Runtime 早期引入 | 桌面复杂度和故障面扩大 | 必须证明多个长任务需要恢复、资源治理或隔离 |
| 批量审核绕过 R5 定稿边界 | 正式知识被错误写入 | 任何 R6 审核能力仍只能生成候选或 ChangeSet，正式写入必须可审计 |
| R4 人工补证长期缺失 | 真实交互质量未知 | 保持延期项可见，不把自动化测试替代人工云端与窗口证据 |
