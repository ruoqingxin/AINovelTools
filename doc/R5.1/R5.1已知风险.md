# R5.1 已知风险

| 风险 | 影响 | 缓解与验收 |
|---|---|---|
| 解除规划阻断后 AI 上下文过少 | 正文可能偏离作者意图 | 提示缺失依据并把未知视为有效状态；保留当前指令、选区、锁定内容和正文修订边界 |
| AI 建议被误当正式内容 | 污染计划或知识 | 所有 AI 输出先进入 Proposal 或候选；正式写入必须由作者确认 |
| 正文提取制造大量待办 | 创作者被审批淹没 | 手动触发、重复内容优先累计证据、低优先级内容折叠 |
| 证据无法定位到原修订 | 候选不可追溯 | 强制保存章节、修订、block、范围和原文哈希 |
| 候选类型被伪装成 Fact | 领域语义失真 | 不使用 Fact 承载角色或伏笔；需要时增加轻量提取候选表 |
| 讨论内容直接改正史 | 可靠性倒退 | 会话表与正式领域表隔离，只能转为候选或临时笔记 |
| 上下文声称读取完整设定 | 模型幻觉被强化 | 无命中时返回明确空语义和来源限制 |
| 文档版本再次漂移 | 迁移和验收依据不一致 | 以运行时 schema version 和 R5.1 Migration 清单共同核对 |

## 2026-10-09 创作闭环优化补充

- 普通正文草稿已独立持久化到 SQLite；800ms 防抖和实际写入仍有保护窗口，不能视为零延迟自动保存。写入错误会保留当前编辑并提供重试与保留副本重读。
- 规划保存已有 CAS 版本检查和提交快照保护；冲突不会自动合并，仍需作者处理。分卷与拆章批量采用整体事务继续延期到 P3。
- 助手、两类检查、提取与事实页签切换已保留面板状态；隐藏面板暂停主动查询和轮询，无本面板任务时停止流监听。已发出的请求仍会完成，全局任务缓存仍由 Shell 刷新。
- 原文证据可以就地查看，打开已保存正文不会重载章节；P2 首批现已补齐精确原修订及 block 定位，失效来源明确拒绝，不回退最新正文。
- 浏览器模拟 IPC 验证已经通过，但不替代真实桌面、多窗口和真实模型验收。
- 迁移 49 已补充历史保留与失败回滚测试，真实桌面进程级异常恢复与含新草稿的人工备份恢复演练仍待 P4。
- 阶段进度与证据见 `../优化/分阶段实施.md`。

## 2026-10-09 候选编辑保护补充

- 保存只确认提交快照，继续输入或改回旧值不会被回执覆盖。无效 JSON 不能保存或采用；拒绝未保存修改需要确认，延期先保存修改。
- 切换章节或离开路由会提示尚未提交的候选编辑和进行中的操作；明确离开后应重读处理结果。未提交提取编辑不是持久化草稿，仍可能在进程退出时丢失。
- 已知提取负载更新时前端阻止覆盖并保留本地内容；后端仍只有状态检查，不能防止未被读取到的同状态多窗口负载覆盖。可靠负载 CAS 继续留待 P3。
- 提取“保存编辑”与“采用”仍是两次调用；采用失败不撤销此前已保存负载，本轮补齐了失败后重新读取和展示，不宣称原子化。
- P1 证据加载按展开状态触发并绑定原修订与 block；P2 首批增加后端完整校验和导航。真实桌面/模型/多窗口验收仍未完成。

## 2026-10-09 可信来源定位补充

- 来源读取核对项目、章节、修订、唯一 block、哈希、锚点状态、版本与 Unicode 字符范围；旧数据不满足这些条件时不能展示为可信证据。
- 历史正文只读，不覆盖编辑草稿，不生成新修订或恢复记录；归档章节只提供来源阅读。
- 索引仍包括正文 JSON，结构元数据与分词命中未必有字面段落；此时只打开修订，没有段落高亮，不伪造证据范围。
- 原生来源链接沿用离开保护，取消离开保留候选编辑；明确离开仍可能丢失尚未提交的候选内容，其持久化和多窗口 CAS 继续留待 P3。
- 浏览器已验证三种尺寸的旧来源往返和失效展示；Tauri 内的导航、真实模型输出证据和多窗口切换仍待 P4 补证。
- P2 的讨论到规划、实体到章节、其他对象导航和上下文复用尚未完成；本批不表示完整关联流程已验收。

## 2026-10-10 讨论与规划往返补充

- 讨论到规划的精确来源往返已实现；流转记录仅表示历史上送入待定区，不证明作者采用了该候选或它仍属于当前正式规划。
- 旧消息按候选绑定的消息 ID 读取，不回退最近消息；项目、会话或目标不一致时明确拒绝。历史元数据不齐全不自动修补，归档目标不接收新晋升。
- 讨论晋升与候选状态同事务，并递增规划版本，阻止旧窗口覆盖新候选；现有规划准入和正式内容不被来源深链绕过或替换。
- 未提交片段修改有离开与切换保护，保存仅确认对应快照；但片段不是 SQLite 持久化草稿，关闭进程或明确放弃仍可能丢失。讨论输入缓存也不等于后端正式消息。
- 三种浏览器尺寸的模拟往返、无效来源、懒查询及规划冲突已验证；真实 Tauri 原生链接、多窗口竞态和模型巡检仍待 P4。
- 实体到章节、其他对象导航与上下文回用仍未完成；本批没有完成完整 P2，也没有实现 P3 候选负载 CAS、批量事务或 DTO 类型生成。

## 2026-10-10 实体与章节联动补充

- 实体与章节双向导航、稳定 ID 关联及当前资料上下文回用已实现；关联不记录已发生事实，不成为角色白名单，也不绕过作者选择的严格准入。
- 选择上限八项，模型附件和 token 预算可能省略其中部分；不得声称模型读取了全部资料。关闭项目知识时不自动带入章节关联。
- 当前实体修订变化会改变关联展示及上下文版本；历史修订不冻结在关联里。需要历史依据时仍须使用正文证据或显式来源，不用当前资料冒充旧版本。
- 已归档资料的旧关联仍可保留/移除，但不会进入活动实体上下文；归档章节关联只读。无效项目/章节/实体不猜测其他对象，历史坏存储不自动修补。
- 关联集合已具备后端 CAS 和原子替换；清空保留版本以拒绝旧窗口。关联失败保留界面选择，重读须明确确认放弃。
- 未提交的关联选择或实体编辑只在当前界面保留，进程退出或明确离开仍可能丢失；显式保存后的关联才受 SQLite 和迁移 50 保证。
- 迁移 50 的历史保留、失败回滚和重试已测试；不承诺旧版降级兼容，含新关联的真实桌面备份恢复与多窗口验收仍待 P4。
- 前端资料读取已收敛为当前实体卡片批量查询，实体导入仍逐条写入，未实现整批事务；提取负载 CAS、批量采用及 DTO 类型生成仍留待 P3。
- P2 其他知识对象导航尚未完成，三种尺寸的浏览器模拟不能代替真实 Tauri、真实模型或进程级恢复补证。
