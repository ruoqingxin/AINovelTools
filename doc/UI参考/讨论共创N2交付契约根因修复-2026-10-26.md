# N2 交付契约根因修复

日期：2026-10-26。依据：[v23 完整真实报告](DeepSeek讨论共创v23全场景真实复测-2026-10-26.md)、[下阶段范围复核](后续流程/讨论共创下阶段复核-2026-10-23.md)。

## 根因与取舍

1. **不是本次续写的历史截断。** v23 对照 `1m8bOB` 的上一回复为 783 个 Unicode 标量，小于单条历史 900 字上限；续写轮 `e26d06bc-cc5d-47d4-94c5-b3fb1a39d474` 的上下文审计保留上一用户/AI 身份，历史序列化 1376 字。失败输出重贴所选方案 244 字，随后只询问是否继续。提高输入预算不能解释或修复这一失败。
2. **执行层把传输结束误作交付完成。** 原 `turn.calls.is_empty()` 直接设置 `COMPLETED`，不区分新增内容与回放；自由文本在完成判断前已流给界面。v23 即使明确禁止重贴，仍会记录为完成。
3. **已读、已送达与已遵守是不同证据。** 短/长自然问句都读取并收到两份准确规则，仍把免除提升代价称为兼容、把窄否定扩大，首次方案也有状态矛盾。召回保护不能验证模型推论，继续堆积提示不能形成执行保证。

本批采用现有工具调用上的窄交付契约，版本 `coauthor-v24`。不换模型、不加固定规划/裁判请求、不加通用真值表、工作流平台或向量专项。历史继续保持 reference-only，不把旧用户指令重播为当前消息。

## 实施

- 普通讨论以 `deliver_reply` 单独交付；成功立即结束，不要求再调用一次模型说“完成”。没有交付工具的自由文本不再作为普通讨论的完成凭据。
- 显式声明 `DISCUSSION / CONTINUATION / REPRINT`，每次必须给出 `ruleChanges`，没有识别到改动时明确提交空数组。工作稿修改和范围查证仍用已有程序回执，不强制第二套收尾。
- 续写需本轮作者准确原话、真实 AI 消息身份、所选方案的 8 至 200 字准确承接点；只交新增正文。压缩后没有原文时必须先读历史，不能猜测另一方案补齐。旧历史的角色另核对原来源零偏移包装，后页伪造角色文字不授予身份。
- 按 Unicode 标量检测续写中连续 80 字逐字复用，与最近 AI 回复及已读承接片段比较；指定保留原句须同时存在于本轮请求和所承接回复。豁免片段分段处理，不拼接两端制造重复；不自动删改文字，不把仅保留原句当新增正文。
- 作者明确要求重贴或整合全文时允许 `REPRINT`，须引用本轮原话；普通问答不做全局去重。模式选择和原话意图仍是模型声明，程序没有自然语言授权判定器。
- 识别到的规则改动单列 `key/revision/quote/proposal`，只接受本轮实际读取且后续送达的正式来源片段，拒绝历史建议、候选摘要、错误版本及伪造引文；交付时再核对当前版本。程序追加“待作者决定、未修改正式资料”的准确提案收尾。
- 自由文本缓冲到审计，交付通过才发布正文；无交付、无效参数和重复交付均累计计数，最多 3 次失败即停止。仍受原单轮 10 请求、金额、取消、项目/会话和输入预算限制，没有独立重试预算，也不重启任务。
- `deliver_reply` 混入其他工具的批次整体拒绝、全部不执行，防止先交付或夹带决定写入。合法交付不修改稿件、正式来源或决定。
- 无 usage 时的输出兜底改按完整回复消息（含工具参数）估算，避免正文放入交付参数后被漏算。提供商有 usage 时仍用实际记录。

## 已知限制

- 80 字检查只能证明逐字重用，不能识别改述、短片段、未读旧页，也不能证明剧情推进。纯粹询问“是否继续”若被错误声明为合法交付，仍需语义复测发现。
- 模型可能选错模式、用无关原话声明重贴、漏列改动或空列 `ruleChanges`。引文真实不代表提案兼容；主体、范围、否定和新机制自洽仍未自动解决。不得把 footer 或 `semanticVerified=false` 改称完整语义验收。
- 不合格自由文本不再流式显示，状态和工具进度仍显示，接受后一次发布；失败/取消文字仅供审计，进程崩溃前尚未收到完整响应的缓冲不保证持久化。不是首字延迟改进，不承诺供应商停止计费。
- 协议增加输入定义及少量参数输出；正常交付不固定增一次请求，失败修正会增加请求。低预算必须用原预算重验，不通过提高 8192 等测试参数掩盖回归。
- 本批没有重新调用 DeepSeek、读取真实凭据或外发作者项目。真实 v24 质量与花费仍未测量；所有历史原报告、冻结样例及人工评分保持不变。

## 数据与阶段边界

schema 65、188 个 IPC 命令/4 个事件保持，无新增数据库字段、迁移、IPC、依赖或历史回填。既有审计 JSON 承载交付、拒绝和缓冲记录；旧运行仍可读取，不追改旧完成状态。

FeatureCatalog 仅登记 `coauthor_reply_delivery` 这一结构、逐字复用和引文身份工程能力，不宣称通用语义判断已实现。仍在 N2，N3/R6/R7、正式采用、长篇副本及发布门禁不自动开启。
