# 讨论共创 N1 状态可信实施记录

日期：2026-10-26。状态：N1 工程交付及本机验收完成，不代表真实模型质量或下阶段整体通过。依据：[下阶段目标](讨论共创下阶段优化目标-2026-10-23.md)及[范围复核](后续流程/讨论共创下阶段复核-2026-10-23.md)。

## 开发范围

- G1：检索响应增加结构化执行状态，区分无效查询、有效返回页、语义未执行与失败；分页、预算省略及索引覆盖保持独立。
- G3：增加讨论决定不写正式资料、准备差异不等于提交的操作正反例。自然语言整段语义质量留给 N2，不用本机固定回复冒充真实模型验证。
- 保持现有作者确认、来源版本、分支隔离、事务、幂等与单轮预算扩容保护。不修改原 13 场景资料或标签。

## 功能目录与迁移

- FeatureCatalog：现有共创能力状态不变；新增窄范围 `coauthor_retrieval_receipts`，由开发中的 `PARTIAL` 更新为 `IMPLEMENTED`，只表示检索执行状态与回执，不表示语义质量通过。
- 无数据库迁移，数据库基线仍为 65。IPC 命令与事件不新增；共享检索响应类型新增执行状态，须重新生成客户端类型。
- 运行标识为 `coauthor-v20`。历史 `coauthor-v19` 真实测评记录原样保留，不追改结果。

## 风险

- 结构化状态须由实际检索分支设置，不解析中文说明，不以关键词规则否定合法单字语义查询。
- 未取得有效结果不能报零；索引待更新不能抹掉确实返回的页计数，也不能被页计数冒充全库覆盖。
- 讨论决定不产生正式同步义务，但不阻断合法的差异准备。模型仍无正式提交工具。
- 不调用收费模型，不读取真实密钥，不发送作者项目；本机回归不代表 DeepSeek 质量通过。

## 实施与复现

- 先新增真实 SQLite/FTS 回归：单字“砂”等输入须返回 `INVALID_QUERY`，有效但无匹配查询须返回 `RETURNED_PAGE`。旧实现实跑失败，实际缺失 `execution`，得到 `null`，保留了可复现证据后才改生产代码。
- `CoauthorSearchPage.execution` 使用枚举。关键词解析器、向量结果与直接关系页按实际执行分支赋值；未授权或无索引的语义入口显式返回 `NOT_RUN`。不解析 coverage 文案，也不把关键词双字规则套到语义查询。
- 运行器仅在明确有效返回页时记录数字。失败优先；状态缺失/未知、缺失 hits、未执行却带 hits 的矛盾结果保守记为 `UNAVAILABLE`。无效查询及未执行的 `returned=null`，不会再显示“实际返回 0 条”。
- 程序回执按查询独立生成，无效查询有行级提示；分页、预算省略及关键词索引待更新单独显示，语义索引快照仍独立。完整审计保留，摘要仍最多显示最近 12 次。
- 新增原生工具分发测试：仅讨论可以记录决定，但不会创建关联采用方案、影响待办或改动正式规则；禁止准备采用。作者允许准备时，无原文和未送达均拒绝；准确读取及送达后可准备，方案为 `PENDING`、`formalCommit=false`，原规则与工作稿保持不变。模型仍无正式提交工具，不增加自然语言授权正则。
- 首次全量尝试发现新测试把 `change_sets` 写成不存在的 `changes` 字段，修正测试后完整重跑；另将测试预期状态按实际契约使用 `PENDING`，没有修改生产状态绕过保护。

## N1 回归尺度

版本 `n1-state-v1`，独立于原固定 13 场景的质量标签；这是开发回归，不是盲测。先冻结以下判据，再按实际执行登记：

| 编号 | 输入与分支 | 必须结果 |
| --- | --- | --- |
| N1-S1 | 关键词“砂”、空白、停用词、单字 ASCII、标点；项目/当前分支历史 | `INVALID_QUERY`，`returned=null`，行级说明不是零命中 |
| N1-S2 | 有效但无匹配的关键词 | `RETURNED_PAGE`，`returned=0`，仍不能证明不存在 |
| N1-S3 | 有候选、后续页、待更新索引与预算省略 | 保留实际页计数，分页/省略/索引分别记录 |
| N1-S4 | 未授权/无向量索引 | `NOT_RUN`，不取凭据、不调用提供商，不报零命中 |
| N1-S5 | 执行失败、未知/缺失状态、缺失 hits、矛盾的未执行且有 hits | `UNAVAILABLE`，不被伪造状态掩盖，不报零命中 |
| N1-S6 | 单字语义查询的有效返回页 | 不套用关键词双字规则，可为真实零页或非空页 |
| N1-A1 | 只讨论并记录不同于正式资料的决定 | 正式资料/工作稿不变，不自动创建采用方案或影响待办；准备请求被拒 |
| N1-A2 | 作者允许准备正式差异 | 无原文/未送达时拒绝；准确读取与送达后允许准备，`formalCommit=false`，资料仍不变 |

回环脚本在原“未检索到不等于不存在”场景追加一次无效查询，不改原资料和预期相关项；必须同时保留有效零页、4 候选页与无效查询三个独立回执。缺少无效回执、把它写成 0 或缺少行级提示均不能通过。
