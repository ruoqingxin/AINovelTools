# 讨论共创 v34 页签与记录整理

日期：2026-10-27。对应本轮四项使用体验反馈，实用优先。

## 改动

- 桌面与窄屏均使用“讨论 / 工作稿”页签，同一时间只展示一个区域。切换时不卸载编辑器，保留未发送输入、工作稿修改及选区。
- 回复底部不再显示历史检索回执、质量说明或核对按钮。回复头部的“查看本轮记录”关联准确回复及运行，顶部统一为“依据与运行记录”。
- 记录面板分为“本轮概览、检索回执、参考资料、运行步骤”。概览保留问题与局限、历史回复、核对入口及改稿差异；检索回执与正文分离，运行步骤沿用中文说明。
- 历史回执只按旧程序的完整末尾格式拆分展示，不改写历史消息。记录读取失败时明确提示无法核实，不把缺记录当作无问题；历史回执仍可独立查看。
- 新增“删除当前讨论”，默认焦点在取消按钮。确认后移除准确讨论、清理该讨论的本机输入及工作稿备份，切到剩余讨论或空状态。原生删除失败时输入及备份不丢失；本地清理失败时明确提示。
- 生成、保存及项目切换期间禁止删除。后端按项目与讨论双重校验，并拒绝仍有运行任务的讨论；删除后迟到的运行结果与旧接口写入不能复活讨论。
- 超长核对请求不覆盖或截断原输入，关闭记录面板后显示错误并聚焦输入框，避免提示被面板遮住。

## 删除边界

本轮删除是持久化的列表移除，不是物理擦除，也没有回收站恢复入口。数据库迁移至 schema 66，使用 `discussion_sessions.deleted_at` 保留不可变来源记录、运行记录及分支快照。

被删除讨论不再进入讨论列表、当前工作区、分支候选、项目历史检索及待处理讨论事项。已经正式采用的内容、其他讨论与分支不变。确认弹窗明确披露这些边界。
