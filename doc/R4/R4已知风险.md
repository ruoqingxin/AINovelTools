# R4 已知风险

- 备份使用本地 SQLite 文件副本，运行中的 WAL 由 SQLite 打开时自动处理；大数据库仍需后续性能基准。
- 恢复默认创建新目录，不覆盖当前项目；附件引用完整性由健康扫描提示，暂不提供自动修复。
- 诊断包仅包含脱敏状态摘要，不包含正文、数据库、Prompt、模型响应、密钥、附件和完整路径。
- Job Runner 当前为单进程轮询执行器，不包含跨进程 Lease、Checkpoint 或独立 Worker。
- 桌面端 UI 已覆盖任务加载、空结果、运行、取消、失败和重试；真实窗口启动失败诊断仍依赖 Tauri 运行环境。
- 真实云端续写、重写、润色、摘要、取消和鉴权失败尚需在用户已配置 Key 的桌面环境完成一次人工冒烟；连接测试通过不等价于完整 AI 闭环通过。
- `R4_SCHEMA_VERSION` 为正式业务数据库版本 14；备份/诊断版本 15 是目录级元数据契约，不应被误解为新增业务表迁移。
