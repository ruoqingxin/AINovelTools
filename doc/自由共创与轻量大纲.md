# 自由共创与轻量大纲

日期：2026-10-13。无需数据库迁移。

## 默认流程

- 大纲入口为本书偏好、故事方向、分卷与章节。
- 本书偏好只记录作者决定的篇幅、风格、表达边界，可包含人称与视角；没有必填项。
- 故事方向是一份可直接编辑的笔记，可只记录开场、近期情节或暂定走向。
- 原有规划项保留在折叠的“规划参考”中，不显示核心项、待明确标签或完成度。
- 写作参考不再列举缺失的规划、人物卡、分卷或钩子，只提示有明确依据的人称冲突。
- 生成本章计划仍可按需使用，不要求先准备全书结构。

## 聊天流转

- 收集片段可记为本书偏好、记入故事方向或用于本章。
- 偏好和故事方向进入现有候选区，由作者采用，不自动替换笔记。
- 用于本章保存为带消息来源及章节目标的 NOTE，不创建章节计划，不修改正文，不触发模型调用。
- 写作链接只携带候选 ID、项目及章节 ID。读取时检查当前项目、章节和候选状态。
- 片段载入可编辑的本次写作要求，作者再选择整章生成、续写或其他操作。
- 收集记录保留回到讨论来源及重新打开目标章节的入口。

## 上下文边界

- `seed-tone` 继续存储本书偏好，旧基调内容及候选原样保留。
- `OUTLINE` 对应的 `plan-node:<id>` 继续存储故事方向，无需重建旧大纲。
- 作者采用且未归档的方向笔记进入写作及讨论上下文；候选不进入方向背景。
- 默认方向是可调整参考，不代表正文已发生。作者锁定的方向仍需遵守，改变须明确授权。
- 新偏好明确人称时优先于旧叙事参考；未明确时继续使用旧叙述设定。
- 未记录项允许在候选正文中创作，不要求预先补齐；作者保留秘密、明确未知和暂不决定仍按作者边界处理。
- 未采用的 AI 建议不自动成为全书事实，知识提炼与证据审核流程不变。
- 保存仍检查原版本，冲突时保留本地编辑，不覆盖远端内容。

## 验证

前端覆盖直接保存、原版本检查、旧候选保留、聊天流转、不自动生成、跨章节误载入及无补全清单。
Rust 覆盖本书偏好人称、开放式写作合同、方向笔记回用、未采用候选及归档方向排除。
浏览器模拟 IPC 检查桌面、窄屏及手机宽度，不调用真实模型。
