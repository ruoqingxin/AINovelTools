## 1. 本批实现

### 共创主工作区

- `/discussion` 默认进入新的讨论与工作稿工作区，支持设定、大纲、正文工作稿。
- 桌面并排编辑，窄屏切换讨论和工作稿；不要求先完成规划表单。
- 流式回复、停止生成、生成中继续手动编辑、停止旧任务后发送新指令。
- 本地恢复副本按项目和讨论隔离，保存失败不清空输入或作者编辑。
- 工作稿自动保存独立修订，支持历史比较及恢复为新修订。
- AI 改稿先成为持久化建议。只有任务仍有效、稿件基础版本相同且本地内容未变化时才自动应用。
- 无法安全应用的结果保留供比较；选中文字可以单独接入工作稿，不连带采用整份建议。
- 来源、决定、版本、运行记录按需展开。

### 原生工具运行

- 使用真实 Chat Completions `tool_calls` / `tool_call_id`，不把普通文本 JSON 当作已执行工具。
- 工具包括检索资料、精读原文、查询讨论历史和决定、读取工作稿、准备局部修改及关联已读来源。
- 每轮默认先进行相关检索，模型可以在同一轮继续查证。
- 真实的工具调用、校验失败、预算限制、模型请求和稿件建议保留在运行记录中。
- 检索命中、执行层读取原文、已随模型请求发送分开标记；不把未发送候选冒充已读依据。
- 每次模型请求接入现有用量记录；不静默重试或切换备用模型，不保存认证密钥。
- 沿用所选讨论模型、温度、输出预算、输入预算和系统表达偏好。

### 持久化与检索

- 数据库版本升至 52，新增工作稿及修订、决定及修订、运行、分支继承、采用回执和增量索引。
- 原始正文、设定、消息和旧修订不删除，不将历史 AI 建议自动升级为正式内容。
- 中文双字词项和英文词项进入独立 FTS 索引；支持名称、别名及少量修炼体系相关的查询扩展。
- 变更触发器只排入脏资料身份；热查询不逐轮全量读取全书。
- 每次检索最多处理 1000 项索引更新，返回 12 条命中和分页信息，同时报告未完成的索引更新。
- 原文读取重新校验当前修订；修订标识包含实际原生版本身份和内容校验。
- 历史讨论检索限定当前分支。显式创建分支时，事务复制继承点的消息、工作稿和决定，后续编辑隔离。
- 作者可纠正或撤回讨论决定，原表达和决定修订保留；决定只适用于当前讨论。
- 项目打开时将孤立的进行中运行标为中断，保留已持久化检查点。

### 正式采用的当前边界

- 正式采用只能由作者在界面查看范围和采用前后内容后确认，AI 没有直接正式提交工具。
- 采用过程具有版本检查、数据库事务及幂等回执，失败不留下半份正式对象。
- 目前仅支持单稿件：新建概念设定卡、新建大纲条目、新建正文章节，以及完整替换已有概念设定卡。
- 完整替换概念卡时，旧结构属性重置为全书设定，旧修订的作者规则不继承；别名、标签和旧修订保留。界面必须明确显示这一范围。
- 已有关联正文与大纲不允许被纯文本工作稿覆盖，避免丢失原富文本结构；需要使用对应正式编辑器。
- 采用后关联到实际正式对象，重复确认同一修订不会重复创建章节。
- 不自动批准正文事实，不自动同步其他章节、设定或伏笔。

## 2. 已验证的安全场景

确定性测试已覆盖：

- 工作稿版本冲突、唯一原文定位、选区越界和未知工具参数拒绝。
- 作者边生成边编辑时保留手动稿件，不用迟到结果覆盖。
- 停止和追加新指令使旧结果失去自动应用资格。
- 停止先于启动到达时持久化取消标记，重开项目后也不执行迟到的同一请求。
- 正式确认期间发生编辑时撤销旧确认。
- 项目身份不匹配时拒绝读写。
- 资料变更后旧引用失效；相同文字的新原生修订也使旧引用失效。
- 讨论决定替代与纠正保留修订，分支继承和后续决定隔离。
- 分支创建失败整体回滚，不留下半个讨论。
- 正式采用失败整体回滚，重复采用幂等，派生搜索索引随提交更新。
- 新正文、大纲创建，以及已有富文本不被纯文本覆盖。
- 检查点重开后保留，未完成结果不自动采用。
- 版本 52 迁移失败回滚并可重试，原始正式正文保持不变。
- 本地 HTTP 模拟提供商的原生工具流式参数拼接与取消，不涉及收费模型。

这些测试证明执行边界，不证明真实模型已经理解所有作者意图或不会产生矛盾。

## 3. 本地检索基线

环境：Windows，Rust 1.98.0，debug 构建。每组 30 次热查询。

样本：一个相关境界设定，加 100 / 600 条无关实体资料。每条无关说明重复 150 次固定文本。旧路径为 `collect_discussion_context_candidates`，新路径为已建索引的 `search_coauthor_sources`。两条路径均不调用模型。

| 无关资料数 | 冷索引 ms | 旧路径 P50 / P95 ms | 新热查询 P50 / P95 ms |
| --- | --- | --- | --- |
| 100 | 145.95 | 8.94 / 9.56 | 0.54 / 0.66 |
| 600 | 923.18 | 60.93 / 63.76 | 0.84 / 0.88 |

每组相关命中 1 条，剩余待索引项为 0，规则的例外条款保留。

这些是合成数据下不同本地查找路径的对比，不是等价创作质量的评分，也不是普通讨论、局部改稿或全书查证的端到端 P50 / P95。

当前仅将“600 条样本冷索引低于 2 秒、热查询 P95 低于 20ms”作为本机初步回归观察线，不当作生产 SLA。真实长篇、真实设备、真实模型的预算与质量门槛仍须补测。

手动复测：

```powershell
cargo test -p novel-infrastructure retrieval_baseline_against_legacy_context_collection -- --ignored --nocapture --test-threads=1
```

## 5. 尚未完成

下列事项仍是本次重构的正式待办，不因当前代码通过测试而降为可忽略项：

1. **关联变更集和影响待办**：正文与设定的整组事务提交、子集依赖检查、受影响章节及伏笔追踪。标准流程第 5.3 节尚未完整实现，因此阶段 B 尚未整体验收。
2. **正式编辑整合**：已有富文本正文和大纲的结构化局部修改，人物、地点、关系等不同对象类型的采用，跨工作稿关联及基本分支合并。
3. **更完整的检索能力**：语义召回、关系及已审核事实扩展、叙事位置和角色知情边界的结构化过滤、索引后台构建、全范围检查的覆盖清单。
4. **长期记忆深化**：决定的对象/故事时间范围、来源依赖失效、稳定主题识别、抑制错误记忆复活的确定性规则。目前主要靠分支状态、来源原话和提示词配合，不能宣称语义判断已解决。
5. **恢复与审计深化**：旧运行分页、精确引用到段落、断点续查、可配置工具轮次与累计费用控制、部分采用的未确认依赖提示。目前单轮有预算保护及最多 10 次模型请求的执行防护，不会无限循环。
6. **隐私策略深化**：资料类别的外发限制和所有派生服务统一检查。当前仅复用模型隐私等级，不代表已经实现文档要求的完整数据发送策略。
7. **创作质量评测**：真实模型的境界扩展/重构判断、长对话指代、最新决定遵从、拒绝方案不复活、作者风格及视角保持。需要另行授权受控费用，不能拿模拟模型结果替代。
8. **旧流程收敛**：规划页内嵌讨论仍使用旧运行接口；版本面板链接到历史构思草稿与候选的 `design=results` 处理入口，避免遗留作者资料失去访问。新主工作区不依赖收集/整理入口，但旧模块尚未删除。
9. **真实项目验收**：空白项目和迁移后的真实长篇副本，连同共创新数据的备份恢复、故障注入及全流程验收。不得直接用作者唯一原项目开展破坏性演练。

下一批优先补齐关联变更、正式富文本编辑整合及影响待办，再扩大真实项目与模型评测。实施继续以效果和安全为准，不以兼容旧界面或“测试数量很多”为完成理由。
