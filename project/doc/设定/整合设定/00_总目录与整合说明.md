# 《末法寻仙》整合设定总目录

## 整合规则

- 来源包括第一版至第七版全部设定。
- 冲突按版本号处理：第七版优先于第六版，依次向前。
- 新版未提及、且不与新版冲突的旧版细节继续保留。
- 第六版文末的“版本冲突最终裁定”继续有效，但其具体机制若与第七版冲突，以第七版为准。
- 原文中的“考虑”“建议”“需要重构”等内容不直接升级为硬设定，统一标成创作建议或待定项。
- 正文统一使用第五版以后确立的新术语，不再使用“仙卡、本命卡、凡卡、灵卡、地卡、天卡、太古仙卡”等旧称。

## 当前核心口径

- “历代至强”指万道纪以来所有合道者；“十位至强”专指黄金大世的十人。
- 每处遗藏都须由一位历代至强的经历与道韵锚定。普通人、群体、地域与时代事件只能作为该至强亲历内容的一部分出现，众生执念不能独立成藏。
- 未知遗藏坐标通过魂印随机发现；成功记录后可在开启期定向接入。稳定化后遗藏转为持续开放的公共查阅入口。
- 对应忆境首次圆满时，汇聚的法则才落到最终载体上，使其成为遗蜕并向现实具现；具现后先进入限时争夺窗口，完成定锚后转为稳定载体或受控现实锚点，完成交付则归入对应道脉或天道，逾期未处理会散逸回收。

## 全书一句话定调

遗藏不是被某个人私有的宝物，而是所有人合力打开的遗迹；圆满不是占有，而是解锁。

## 核心主题

一个人能否拒绝占有先人的遗产，也拒绝重复先人的牺牲，走出一条从未有人走过的路。
