# 势力格局

## 域外联军

域外联军由多个文明组成，遵循削弱派的“弱而不灭”战略。五位极妄境巅峰统帅中，三位常驻外四域，另两位驻守界外虚空堡垒。

常驻占领军完全控制核心死寂区，在深度腐化区建立适合执妄道生存的腐域。他们视本土生灵为奴隶，销毁灵气道统，以扫荡、捕奴、污染和连接干扰消耗本界。

“弱而不灭”要求他们同时守住两条边界：不能允许本界积累出再次晋升的力量，也不能令世界本源和本土人口彻底死亡。高阶道统、关键灵脉和可能修复世界的遗藏是优先摧毁目标；维持最低世界活性的低品遗藏、聚落与商路则会被征税、污染和控制，而不是全部清除。

执妄道无法稳定接入本界魂印网络，修至阴婴后魂印更会彻底失效。域外联军因此难以直接搜索大多数未知遗藏，只能依靠投降者、被胁迫者和掠灵势力提供坐标。这既限制了他们摧毁遗藏的效率，也使本土代理人成为长期统治的核心。

## 溯光时尊势力

由溯光时尊及投降、投机、被胁迫的本土修士组成，是域外扫荡与捕奴的主要执行者。高层多转修执妄道，神魂受域外禁制；他们既不被域外信任，也保留自己的底牌。

该势力主要控制深度腐化区，并向缓冲带派遣扫荡队。

## 外域原住民

未能迁入中州的幸存者后裔，以部落、宗门残部和散修聚落为单位生活。普遍修为不高，却熟悉废土环境与遗藏分布。

他们依靠魂印与低品遗藏获取粮食、药物和修行资源，对中州既依赖又怨恨：依赖传火者维持通道，也怨恨中州当年放弃外域。

## 传火者前线

中州传火派派出的精锐小队，负责建立忆境锚点、记录遗藏坐标、救援原住民、净化污染和袭击小型据点。以缓冲带为根基，逐步向深度腐化区渗透，避免与域外主力正面对抗。

## 中州传火派

- 目标：恢复遗藏、修复天道、收复四域并再次晋升大千。
- 基础：古老道统、年轻修士与底层群体，外域传火者为直属力量。
- 风格：主动推进高阶探索，投入外域战线，行动较激进。
- 短板：掌握的优质灵脉和高阶资源少于保守派。

## 中州保守派

- 目标：固守中州、控制复苏速度、放弃或长期延缓晋升。
- 基础：顶尖门阀和大宗门，掌握多数优质灵脉与高阶坐标。
- 理念：再次晋升会引来全面围攻，偏安是当前最现实的生存方式。
- 暗线：极少数高层与域外暗中交换情报，以换取边境安宁。

## 中立与灰色势力

### 噬灵宗

走掠灵路线，强行抽取遗藏表层灵性。受保守派和部分域外势力默许，是多方博弈的灰色棋子。

### 守忆一脉

认为遗藏属于众生共同遗产，既反对传火派冒进，也反对保守派放任掠灵。常年在废土回收、记录和净化污染遗藏。

### 散修

没有固定阵营，多数偏向能提供更多探索机会的传火派，但立场会随生存与利益变化。
