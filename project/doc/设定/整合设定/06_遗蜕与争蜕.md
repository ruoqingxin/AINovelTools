# 遗蜕与争蜕

本文只定义遗蜕的通用机制。所有已经命名的单件遗蜕统一登记在[《遗蜕登记总表》](16_遗蜕登记总表.md)，具体来源、妙用与归属以总表为准。

## 遗蜕定义

遗蜕不是历史中早已存在的法则物，也不是进入遗藏后随机捡到的特殊掉落。它只在对应忆境第一次圆满，也就是遗藏恢复进度达到100%、完成稳定化时诞生。

忆境圆满后，原本散落在核心记忆中的至强法则重新汇聚。天道先回收三成用于维持忆境与世界，剩余法则则在忆境内部落到一个与来源大道、载体性质和本次恢复结果最契合的事物上。被法则最终选中并结合的那个事物，从这一刻起才称为“遗蜕”。圆满之前，它无论是凡物、灵物还是自然现象，都只能称为候选载体，不能提前称作遗蜕。

能够承接法则的不限于普通器物，也可以是灵器、矿石、植物、异兽或修士遗骸、建筑残片，以及忆境中被稳定下来的水、火、风、雾等自然现象。原本就是灵物的载体不会失去原有效果，而是在原有性质上叠加或异化出新的法则妙用。

同一遗藏可以预设多个候选载体，但圆满时通常只产生一件遗蜕。法则最终落到何物上，会受到最后完成的核心任务、主要恢复路线和锚点至强关键选择的影响。一旦落定，结果不再随后续重复探索改变。

遗蜕妙用由四项共同决定：

1. 来源法则决定能力方向，例如火道通常涉及燃烧、温度、转化与淬炼。
2. 载体性质决定能力表现，同一火道落在炉钳、树种和泉水上，会形成完全不同的妙用。
3. 圆满时的法则融合强度决定效果上限、范围、持续时间与使用代价。
4. 圆满路径决定最终载体与触发倾向；最后被修复的选择会在遗蜕限制中留下痕迹。

遗藏稳定化后，遗蜕会在现实对应坐标附近以可感知、可干预的载体投影出现。器物、矿石、植物或遗骸类会凝成实体；水火风雾、地形或建筑类则依附现实锚点稳定显化。下表时间是公开争夺与定锚窗口，不是自用后的总寿命：

| 来源品级 | 争夺窗口 |
| --- | --- |
| 凡忆 | 3天 |
| 玄章 | 7天 |
| 地书 | 15天 |
| 天图 | 1个月 |
| 道藏 | 数月以上 |

## 法则融合强度

| 品级 | 圆满后的融合程度 | 衍生妙用上限 | 碎片价值 |
| --- | --- | --- | --- |
| 凡忆·薄 | 法则只附于载体表面，如落灰 | 极微弱 | 极少 |
| 凡忆·普通 | 法则略微渗入载体 | 微弱 | 少量 |
| 凡忆·厚 | 法则渗入载体表层 | 明显 | 少量以上 |
| 玄章 | 法则渗入载体内部 | 较强 | 中等 |
| 地书 | 法则与物品基本融合 | 强 | 大量 |
| 天图 | 载体高度法则化 | 极强 | 丰沛 |
| 道藏 | 载体与本源碎片难分 | 承载大道本身 | 核心级 |

示例：同一把刀在圆满后承接同一大道，融合强度从凡忆·薄到天图提升时，妙用可由“比原本稍利”逐步上升为“挥刀无声”“短暂消失半息”“自动偏转形成必中”乃至“随意念换手”。若最终载体换成树种、残骨或一团炉火，即使承接同一大道，也应沿载体性质衍生不同妙用，不能套用刀类效果。

## 三种去向

| 选择 | 获益者 | 结果 |
| --- | --- | --- |
| 自用 | 定锚者 | 投影转为稳定载体，获得法则妙用；碎片随使用逐渐消耗 |
| 交易 | 至强代理人或相关势力 | 换取资源、功法、情报和关系 |
| 交还 | 至强或天道 | 碎片归位，补全大道或世界 |

自用定锚后仍可转交，但每次改换道韵归属都会损耗碎片，且已消耗的部分不能恢复。提炼或释放完碎片后，载体失去新增的法则妙用并恢复原始性质；原本是灵物的仍是灵物，原本是凡物的才会回归凡物。自然现象类遗蜕失去法则后通常直接消散。在争夺窗口内整件交付损耗最低、收益通常最高，但持有者彻底失去控制权。

只有天道和至强能真正提炼法则碎片，普通修士只能引导释放或转移交付。

### 源头

对应忆境首次圆满（遗藏恢复达到100%） → 至强法则在忆境核心汇聚 → 天道回收三成 → 余下七成法则落到忆境内最契合的候选载体 → 载体在此刻成为遗蜕 → 遗蜕向现实对应坐标投影具现。

### 流向

遗蜕最终流向三个方向：修士定锚自用、至强代理人或宗门接收、逾期后由天道自然回收。三种流向之间存在取舍竞争。

### 层级结构

大势力处理遗蜕有明确的层级分工，低阶执事负责日常收储，高阶修士只在特定条件下介入。筑基期执事用定道石、骨针、余烬灯等工具完成鉴伪定价，不需要高深修为。长老只在出现地书级以上遗蜕、执事遇到无法判断之物或出现值得关注的散修时出面。

## 交付方式

- 至强代理人移交：交给对应至强的后人或道脉，通过血脉、道印链接传递。
- 节点释放：把遗蜕放到对应至强的坐标，主动断开连接，使碎片流向对方。
- 天道自然回收：争夺窗口结束时仍未定锚或交付，投影立刻散逸，剩余碎片由天道回收。
- 天道强制抽成：稳定化时，天道已经自动抽取30%。

普通修士引导释放损耗10%至20%；林澈因双核灵魂，损耗不到一成。

## 清浊道的特殊性

林澈融合澄浊元君本源，能直接吸收清浊道法则碎片，其他大道的碎片不能吸收。这不是提炼，而是同源归位。

| 项目 | 规则 |
| --- | --- |
| 触发 | 魂印自动感知，右手印记发热 |
| 过程 | 触摸遗蜕，碎片流入魂印并融入元君本源，持续10至数十息，期间无法移动 |
| 显性效果 | 净化、污染能力更稳定，消耗更低，手背印记加深 |
| 隐性效果 | 解锁元君记忆；后期可更低损耗引导其他大道碎片 |
| 限制 | 有承载上限；吸收后冷却1至3天；品级过高可造成魂印裂痕；过程可被打断 |
| 代价 | 灵力临时抽空三成，神识昏沉半日 |

天道抽成仍然有效；林澈吸收的是天道抽取30%后的剩余部分。

## 稳定化后的具现流程

1. 恢复进度到达100%，核心记忆闭合，至强法则在忆境内部重新汇聚。
2. 天道回收三成法则，余下部分根据最终恢复路径落到一个候选载体上；该载体在此刻成为遗蜕。
3. 遗藏内部的意识回响完成最后动作并进入静默，仅贡献排名前列者能看见法则落定的完整过程。
4. 遗蜕向现实对应坐标投影。天地回响随品级增强：凡忆只有极淡光柱，玄章为光柱加钟鸣，地书以上可令天地变色。
5. 投影稳定显化耗时1至2个时辰。实体载体逐渐凝实，自然现象或地形载体则形成现实锚点；期间不能转移或定锚，但可以被破坏、扰乱。
6. 显化完成后进入公开争夺窗口。窗口结束前，持有者须以魂印定锚自用或完成交付；逾期未处理则遗蜕散逸回收。

遗蜕只在对应忆境第一次圆满时生成并具现一次。稳定化后的重复探索不会重新汇聚该次法则，也不会重复生成遗蜕。

## 锚点回响处理

| 品级 | 稳定化后的表现 |
| --- | --- |
| 凡忆 | 完成最后动作后静默，不再移动 |
| 玄章、地书 | 说出与执念对应的完整话语，化为微光融入灵性虚空 |
| 天图、道藏 | 至强人格投影与时代群像化为天道底色或回响合音 |

稳定化不是复活，也不是删除，而是执念完成后静默或升格。情感收束保持轻：少对话、少告别、少抒情，把叙事重心转向遗蜕的价值与现实争夺。

## 争蜕规则

- 遗蜕坐标经魂印向相应范围广播，附近修士都可感知；恢复参与者优先得到消息。
- 争夺者包括恢复参与者、附近散修与掠灵者、中州势力、至强代理人和域外势力。
- 可移动的实体载体能够被转移、抢夺、损坏或摧毁；建筑、地形与自然现象类遗蜕不能直接搬走，争夺围绕其现实锚点和控制权展开。
- 争夺窗口内，持有不等于最终归属；完成魂印定锚或正式交付后才算结算。
- 窗口结束时仍未结算，遗蜕投影散逸，剩余法则碎片由天道回收。
- 严重损坏可能导致品阶跌落；彻底摧毁则本次遗蜕永久消失，但不影响已稳定化遗藏的公共查阅。
