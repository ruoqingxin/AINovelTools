# 遗蜕登记总表

## 文档职责

本文件集中登记所有已经进入设定、主线或伏笔的遗蜕，是单件遗蜕来源、能力、限制、具现和归属的唯一权威记录。

- 《遗蜕与争蜕》只负责遗蜕通用机制。
- 地图文档只记录该地图会产生哪件遗蜕，以及争蜕如何承接地图剧情。
- 主线文档只记录遗蜕在情节中的出现、争夺与人物选择。
- 单件遗蜕的具体能力、限制或来源发生变化时，只在本文件修改，再检查其他文档中的剧情引用。

任何已命名遗蜕都必须先取得登记编号，才能写入地图或主线。暂时只有概念、尚未确定载体与来源的内容统一列入“待设计”，不得当成硬设定使用。

## YT-001：藏谷铜斗

### 来源

| 项目 | 设定 |
| --- | --- |
| 对应遗藏 | 《雨仓镇》 |
| 锚点至强 | 万道纪一位尚未具名的至强；完整大道不在前期披露 |
| 锚点阶段 | 筑基时期 |
| 关键历史 | 暴雨灾年，年轻至强曾用此斗分发种粮，并在“封仓保粮”与“开仓救人”之间作出影响一生的选择 |
| 候选载体 | 缺口铜斗、官仓门锁、最后一袋种粮、崩裂水门 |
| 最终恢复路径 | 林澈没有单纯守仓或放粮，而是疏散灾民、保住种粮并按需分配现粮 |
| 法则落定 | 《雨仓镇》忆境首次圆满时，汇聚的容纳与守藏法则没有落到代表封闭的门锁，也没有落到一次性消耗的种粮，而是落到兼具“计量、分配、保存”意义的铜斗上；铜斗在这一刻才成为遗蜕 |
| 来源品级 | 凡忆·厚 |

### 载体与妙用

| 项目 | 设定 |
| --- | --- |
| 载体原貌 | 官仓使用的缺口铜量斗，原本没有稳定灵性 |
| 核心妙用 | 外观只能容一斗，内部可收纳约五百斤同类干燥颗粒；总重量不变，内容不会受潮、发霉或生虫 |
| 法则延伸逻辑 | “容纳”扩大内部容量，“守藏”维持内容状态；量斗只能承载其原本用于计量、保存的颗粒类物资 |
| 可存放 | 灵谷、种子、盐、药粉、矿砂等无生命颗粒 |
| 不可存放 | 活物、液体、完整器物、法术与未稳定的法则碎片 |
| 使用限制 | 一次只能保存一类；取放需要十息；载体破损后内容会一次性倾出 |
| 法则耗尽 | 铜斗失去内部容量与保全效果，恢复为缺口凡器 |

### 具现与剧情

| 项目 | 设定 |
| --- | --- |
| 具现条件 | 《雨仓镇》第一次达到100%恢复进度 |
| 具现地点 | 灰岩部落外被泥沙掩埋的旧粮仓遗址 |
| 主要争夺者 | 石坚派、部落凡人、附近粮商、外来散修 |
| 核心冲突 | 卖出铜斗可以立即补足一次税款，留下铜斗则能长期保存灵谷、种子与药粉 |
| 争夺结果 | 林澈利用贡献排名抢先守住具现地点，但拒绝私人定锚 |
| 最终归属 | 石厚代表部落定锚，铜斗嵌入公共粮仓；出入账由陈三更与凡人粮官共同核对 |
| 后续作用 | 降低灰岩粮药损耗，成为林澈第一次明确拒绝私人占有遗产的选择 |

## YT-002：雾路驿铃

### 来源

| 项目 | 设定 |
| --- | --- |
| 对应遗藏 | 《雾岭驿道》 |
| 锚点至强 | 万道纪一位尚未具名的至强，偏向风道、回响与行路 |
| 锚点阶段 | 筑基后期 |
| 关键历史 | 药材商队遭伏击后，年轻至强曾反复摇响领车铜铃，试图在浓雾中召回失散者并寻找生路 |
| 候选载体 | 裂纹铜铃、折断路碑、领车车轮、雾谷中的一缕长雾 |
| 最终恢复路径 | 林澈小队放弃最短出口，修复货车、召回失散队员并共同完成条件撤离 |
| 法则落定 | 《雾岭驿道》忆境首次圆满时，风、回响与行路法则落到代表“召回同伴并一起找到出路”的铜铃上，而不是只代表速度的车轮或只指固定方向的路碑；铜铃在这一刻才成为遗蜕 |
| 来源品级 | 凡忆·厚 |

### 载体与妙用

| 项目 | 设定 |
| --- | --- |
| 载体原貌 | 商队领车悬挂的裂纹铜铃，原本带有微弱示警灵纹 |
| 核心妙用 | 在浓雾、黑暗或复杂地形中摇响，可用回声指出三里内最近一条仍可通行的现实路径，持续约三十息 |
| 法则延伸逻辑 | 风道传递铃音，回响判断阻隔，行路道韵从可达路径中选择最近者；铜铃原有示警能力被放大为指路能力 |
| 判断范围 | 只确认道路当前可以通行，不判断道路是否安全、是否有埋伏或是否通向使用者真正想去的位置 |
| 使用限制 | 一日最多稳定使用一次；强行再次摇响会产生相互冲突的回声；不能直接定位忆境撤离点或遗藏坐标 |
| 法则耗尽 | 失去指路能力，但保留原有的微弱示警灵纹 |

### 具现与剧情

| 项目 | 设定 |
| --- | --- |
| 具现条件 | 《雾岭驿道》第一次达到100%恢复进度 |
| 具现地点 | 雾岭现实山道上一座只剩半边屋顶的废弃驿亭 |
| 主要争夺者 | 撤离堵门者、商队、传火者外围人员、林澈小队 |
| 核心冲突 | 各方都知道驿铃无法寻宝，却能显著提高废土行军、商路运输和迷雾撤退的存活率 |
| 争夺结果 | 苏晚利用旧驿路和假脚印绕过埋伏，在林澈正面牵制时完成定锚 |
| 最终归属 | 苏晚保管，作为林澈小队共有路线工具 |
| 后续作用 | 支撑废土远行；驿铃对苏晚魂印反应过于顺畅，成为其传火者身份伏笔 |

## YT-003：吞火炉钳

### 来源

| 项目 | 设定 |
| --- | --- |
| 对应遗藏 | 《沉炉城》 |
| 锚点至强 | 万道纪一位尚未具名的火道至强 |
| 锚点阶段 | 金丹时期 |
| 关键历史 | 沉炉事故中，年轻至强曾用此钳夹出失控炉心，在保住一炉重器与疏散矿工之间作出选择 |
| 候选载体 | 隔热炉钳、失控炉心、冷却主阀、主炉中未熄的火种 |
| 最终恢复路径 | 林澈小队开启冷却水道、疏散受困者并夹出炉心，没有选择引爆整座主炉或独占成品 |
| 法则落定 | 《沉炉城》忆境首次圆满时，火道法则没有落到只会释放力量的炉心，而是落到承担“接住、转移、再利用”作用的炉钳上；炉钳在这一刻才成为遗蜕，并衍生出吞纳与转移热量的妙用 |
| 来源品级 | 玄章·普通 |

### 载体与妙用

| 项目 | 设定 |
| --- | --- |
| 载体原貌 | 主炉工匠使用的长柄炉钳，原本就是可隔绝高温的炼器灵具 |
| 核心妙用 | 可夹持高温物体而不向使用者传热，并缓慢吸收相当于一次筑基初期火法的热量 |
| 法则延伸逻辑 | 原有隔热灵纹负责承受接触，火道碎屑把“隔绝”延伸为“吞纳”，再允许把储热转移给炉火或目标 |
| 储热用途 | 为炼器炉补火、预热灵材，或一次释放为近距离热浪 |
| 使用限制 | 只能吸收热量，不能吞噬其他术法；释放后需自然冷却一日 |
| 反噬 | 储热超过上限会使钳身开裂，并沿定锚联系灼伤韩岳双臂与经脉 |
| 法则耗尽 | 失去吞纳和释放热量的妙用，但仍保留原有隔热灵具效果 |

### 具现与剧情

| 项目 | 设定 |
| --- | --- |
| 具现条件 | 《沉炉城》第一次达到100%恢复进度 |
| 具现地点 | 西风堡势力边界内一座熄灭多年的露天废炉场 |
| 主要争夺者 | 西风堡代理人、中州商队、地方炼器势力、灰岩部落 |
| 核心冲突 | 炉钳兼具生产与战斗用途，谁得到它，谁就能降低炼器成本并储存一次筑基级火力 |
| 争夺结果 | 林澈公开沉炉订单打乱代理人身份掩护，苏晚封锁退路，韩岳在冷炉旁完成定锚 |
| 最终归属 | 平时存放于灰岩公炉用于锻造，外出时由韩岳携带 |
| 后续作用 | 提升部落炼器能力与韩岳战斗上限，也使韩岳成为西风堡和炼器势力优先针对的目标 |

## 防遗漏检查

1. 新增或命名遗蜕时，先在本文件分配唯一编号。
2. 检查来源遗藏、锚点阶段和忆境首次圆满时汇聚的法则方向是否一致。
3. 检查候选载体、最终恢复路径和法则落点是否存在清晰因果，不能默认某件旧物早已是遗蜕。
4. 检查妙用能否从来源法则与载体性质共同推导，不能只写抽象能力。
5. 检查强度是否符合来源品级，并写明限制、反噬和法则耗尽结果。
6. 检查具现地点、争夺窗口、争夺者、定锚者和最终归属是否齐全。
7. 检查主线是否写出争蜕结果，地图是否明确首次具现后仍可重复探索。
8. 检查人物与伏笔文档是否记录遗蜕带来的长期能力、责任与敌人。
