第一篇：世界基石
一、世界本质
本界为中千世界，法则不全，有境界上限。晋升大千是核心驱动力。

纪元道韵：修士合道后，道印与世界本源绑定，形成纪元道韵。常态下，中千世界只能承载一枚合道果位，一纪元约十万年。同途修士获得修行速度、突破率、战力、法则领悟等加成。

黄金大世：晋升窗口开启，法则临时扩容，十条纪元道韵同时覆盖，十位至强分镇五域。

超时撤离：忆境演化完毕后未撤离，失去所有虚影 + 神魂创伤 + 短期禁入

撤离后永远回到接入时的现实坐标，不能借忆境跨地域移动。

第三篇：遗蜕与法则碎片
一、遗蜕的定义
遗蜕 = 一件普通物品 + 一丝大道法则碎屑（沾染/附着）

忆境中的记忆场景里，某件物品“刚好”被某位至强散逸的道韵擦过，于是沾上了法则气息

不同品级忆境，沾染强度不同

遗蜕出现在现实世界对应坐标附近，以实体投影形式存在

存在时间：凡忆3天 / 玄章7天 / 地书15天 / 天图1月 / 道藏数月以上

交还	至强/天道	法则碎片归位，补全大道或世界
四、使用与提炼的矛盾（核心抉择）
选择	好处	代价
自用	立刻获得神奇效果	碎片困在物品里，不能交易或归位
提炼	碎片可用于交易/归位	物品变回普通凡物，神奇效果消失
整件交出	换最多东西	完全失去控制权
提炼法则碎片只有天道和至强能做到。修士只能“引导释放”或“转移交付”。

五、法则碎片交付方式
至强代理人移交：把遗蜕交给对应至强的后人/道脉，通过血脉或道印链接传递

节点释放：把遗蜕放到对应至强的“坐标”，主动断开连接，碎片自然流向该至强

天道自然回收：遗蜕长时间未处理，法则缓慢散逸，被天道回收（半年至一年，效果逐渐衰减）

天道强制抽成：遗藏稳定化时天道已自动抽取30%

普通修士引导释放有10%-20%损耗。林澈因双核灵魂，损耗极低（不到一成）。

六、清浊道的特殊性
林澈因融合澄浊元君本源，能吸收清浊道法则碎片（其他道不可）。

这不是“提炼”，是“同源归位”。

第八篇：结局走向
本界成功晋升大千。林澈以清浊大道执行反向道祭，以域外本源为燃料。溯光时尊反水切断外援。大千法则降临后，天道修正并永久废止旧道祭程序。林澈以自己的身份走向渡劫成仙之路。

主角不牺牲坐镇，不被取代。核心主题：一个人能否拒绝占有先人遗产，也拒绝重复先人牺牲，走出一条从未有人走过的路
